## 二、⭐ 能"自动回复"的话术清单（重点）

系统是**两级应答**：先查知识库（**秒回、不花钱**），查不到才调用大模型（**约 2~3 秒**）。

### 2.1 知识库秒回话术（命中即回，零 API 成本）

**命中规则**：你的输入里**包含主题词或别名词**即命中（先匹配先返回）。

#### 电商用户（登录时选择「电商用户」）

| 输入包含这些词 | 系统自动回复（原文） |
|---|---|
| 订单查询、订单、快递到哪、我的单 | 您可以通过订单号在官网查询订单状态，通常在24小时内更新。如需人工协助，请提供订单号。 |
| 物流跟踪、物流、快递、发货 | 物流信息可通过快递单号查询，支持圆通、中通、顺丰等主流快递。 |
| 退换货、退货、换货、退款 | 7天内可申请退换货，请提供订单号和退换货原因，我们会尽快处理。 |
| 支付问题、支付、付款、付钱 | 支持微信支付、支付宝、银行卡等多种支付方式，如遇支付问题可联系客服。 |
| 优惠券、优惠、券、折扣 | 可在购物车页面使用优惠券，满100减20等优惠活动持续进行中。 |
| 会员服务、会员、积分 | 成为会员可享受积分兑换、专属折扣、优先发货等权益。 |

#### 企业用户（登录时选择「企业用户」）

| 输入包含这些词 | 系统自动回复（原文） |
|---|---|
| 订单管理、批量订单、企业订单 | 企业客户可通过企业账户批量管理订单，支持批量导出和统计分析。 |
| 批量采购、采购、批发、大单 | 支持批量下单和定制化服务，量大从优，详情咨询专属客户经理。 |
| 售后服务、售后、技术支持、报修 | 提供7×24小时技术支持，专业响应时间≤30分钟，保障企业业务连续性。 |
| 定制开发、定制、开发方案 | 可根据企业需求提供定制化解决方案，包括API对接、系统集成等。 |
| 数据报表、报表、数据导出、分析 | 提供详细的销售数据和客户分析报表，支持自定义报表和数据导出。 |
| API对接、API、接口、系统对接 | 支持标准化API接口对接，实现系统自动化，提升运营效率。 |

> 💡 小提示：英文「API」需**大写**才会命中知识库（小写 api 会交给大模型回答）。
> 💡 侧边栏的「📌 快捷问题」按钮 = 直接发送这些主题词，一键触发秒回。

### 2.2 未命中 → 大模型智能回答（真 AI）

知识库没覆盖的问题，会带着**最近几轮对话上下文**交给大模型（qwen3-max）回答。可以直接演示：

- `你们营业时间是几点？`
- `可以预约售后上门吗？需要什么条件`
- `如果我不想要了，但超过7天了怎么办`
- `帮我写一段给客户的促销话术`

回复末尾会标注来源，例如「来源：大模型 qwen3-max」，方便向面试官证明这是真实模型输出。

### 2.3 大模型不可用时的兜底

若网络/额度异常，系统**不会卡死**，而是回复：

> 您好！关于"×××"，知识库暂时没有现成答案。您可以稍后再试，或先尝试"订单查询 / 物流跟踪 / 退换货"等快捷问题。

（并标注「来源: 兜底话术」）

## 三、演示脚本（面试/展示照着念）

1. **登录**：输入手机号 → 点「微信登录」（说明：真实项目可接微信授权，演示版用手机号占位）
2. **秒回演示**：点侧边栏「📌 订单查询」→ 立刻回复 → *"这条走本地知识库，毫秒级返回、零 API 成本"*
3. **真 AI 演示**：输入「你们营业时间是几点」→ 等 2~3 秒 → *"这条知识库没有，系统自动调用大模型生成，回复来源标注了 qwen3-max"*
4. **多轮记忆**：接着问「那周末呢？」→ 大模型会结合上一句回答
5. **多角色**：左侧「切换用户类型」→ 选「企业用户」→ 问「批量采购」→ 秒回企业话术
6. **收尾**：点「🗑️ 清空对话」或「🚪 退出登录」

**一句话总结给面试官**：*"这是两级应答架构——高频问题走知识库做到零成本秒回，长尾问题走大模型保证可用性，并且用 SQLite 保存会话实现多轮上下文。"*

## 四、微信端（可选）

项目内含 `wechat_bot.py`，实现了微信公众号服务器：URL 签名校验 + XML 消息收发 + 复用同一套问答核心。

```bash
.venv\Scripts\python.exe wechat_bot.py --selftest   # 本地模拟微信消息，验证链路
.venv\Scripts\python.exe wechat_bot.py               # 启动微信服务（:8001）
```

**真实接入需要**：公网可访问地址（内网穿透或云服务器）+ 公众号后台「服务器配置」填 URL 与 Token（Token 见 `.env` 的 `WECHAT_TOKEN`）。详见 `docs/微信接入步骤.md`、`docs/StreamlitCloud_部署步骤.md`。

## 五、常见问题

| 现象 | 原因与解决 |
|---|---|
| 大模型回复变成"兜底话术" | 云端未配置 `DASHSCOPE_API_KEY`（Streamlit Secrets / 本地 `.env`），或网络/额度异常 |
| 本机启动报缺模块 | `pip install -r requirements.txt`（推荐在项目自带 `.venv` 里装） |
| 回复很慢 | 知识库是毫秒级；大模型路径需 2~3 秒，属正常 |
| 想换模型 | 改 `.env` 的 `LLM_MODEL`（如 `qwen-plus`、`qwen-turbo`） |
| 聊天记录在哪 | 项目目录 `ai_customer.db`（SQLite），关掉程序也不丢 |
