# 微信接入保姆级步骤（照做即可）

> 目标：用户在你的**订阅号**里发消息 → 你的电脑程序自动用 AI 回复。
> 需要：① 本机跑起 wechat_bot ② 一个“公网门牌”（内网穿透）③ 公众号后台填两个东西。
> 全程 0 费用（用免费内网穿透）。

---

## Step 0 · 确认现状
- 已注册**订阅号**（个人主体）并能在 mp.weixin.qq.com 登录 ✅
- 项目 `D:\求职简历修改方案\AI客服助手项目\.env` 中已有 `WECHAT_TOKEN=ai-customer-service-token` ✅

## Step 1 · 本机启动微信服务（我已帮你起好可跳过）
```bat
cd /d "D:\求职简历修改方案\AI客服助手项目"
.venv\Scripts\python.exe wechat_bot.py
```
浏览器打开 `http://127.0.0.1:8001/health` 应显示 `{"status":"ok","llm_configured":true,...}`。
自测（不依赖微信）：
```bat
.venv\Scripts\python.exe wechat_bot.py --selftest
```

## Step 2 · 给你的电脑开一个“公网门牌”（内网穿透，用 cpolar 免费版）
1. 打开 https://www.cpolar.com 注册/登录（手机号即可）。
2. 登录后进入 **仪表盘 → 左侧“验证”**，页面上有一串 `authtoken`（形如 `xxxxxxxx`）。
3. 下载 Windows 客户端并解压，或直接命令行安装：
   - 官网下载 zip → 解压得到 `cpolar.exe`，把它放到比如 `D:\cpolar\`。
4. 打开 CMD，执行（换成你自己的 token）：
   ```bat
   D:\cpolar\cpolar.exe authtoken 你的authtoken
   D:\cpolar\cpolar.exe http 8001
   ```
5. 看到输出里有 `https://xxxxxxxx.cpolar.cn` 之类的一行 = 成功。这就是“公网门牌”。

⚠️ **注意**：免费版每次重启 cpolar 会换新地址。配置好微信后**不要重启 cpolar**；
要长期稳定可买 cpolar 基础套餐固定域名（约 10 元/月，可后置）。

## Step 3 · 公众号后台配置（让微信把消息转给你）
1. 登录 https://mp.weixin.qq.com （你的订阅号）。
2. 左侧菜单：**设置与开发 → 基本配置**。
3. 点 **服务器配置** 区域的 **修改配置/启用**：
   | 填项 | 填什么 |
   |---|---|
   | URL（服务器地址） | `https://你上面得到的cpolar地址/wechat`（注意别漏 `/wechat`） |
   | Token（令牌） | `ai-customer-service-token` |
   | EncodingAESKey | 点“随机生成” |
   | 消息加解密方式 | 选 **明文模式** |
4. 点 **提交**。
   - 微信会立刻 GET 你的地址验证签名。
   - 显示类似“**配置成功，Token验证通过**”= 打通！我们的 `wechat_bot.py` 会自动回应验证。
   - 若提示失败：看文末“常见问题”。
5. 提交成功后，回到 **基本配置**，确认 **服务器配置状态是“已启用”**（不是停用）。

## Step 4 · 真机测试
1. 手机微信搜索并关注你的订阅号。
2. 在对话框发：`订单查询`
   → 应**秒回**知识库答案（说明链路通）。
3. 再发：`你们营业时间是几点？可以预约吗`
   → 大模型回答（可能要 5~10 秒）。

⚠️ 微信限制回复必须在 **5 秒内**；大模型超时会显示“该公众号暂时无法提供服务”。
跑通后若要优化，找我做“先回一句受理 + 稍后补发”的升级版。

## 常见问题（FAQ）
| 现象 | 原因与解决 |
|---|---|
| 提交配置提示“URL 验证失败 / Token 验证失败” | ① cpolar 没在跑/换地址了 → 重新复制新地址；② URL 少写了 `/wechat`；③ wechat_bot 没在运行 → 回到 Step 1；④ Token 与 .env 不一致 |
| 显示“该公众号暂时无法提供服务” | 回复超 5 秒（LLM 太慢）。先试知识库问题确认链路；或找我升级异步回复 |
| 个人订阅号某些功能提示受限 | 正常。被动文本回复是基础能力，个人订阅号可用 |
| cpolar 免费地址变了 | 重新填公众号后台 URL（并保持 cpolar 别重启） |
| health 显示 llm_configured:false | .env 没写 DASHSCOPE_API_KEY → 检查项目 `.env` |

**遇到任何一步不对，把屏幕提示发给我，我帮你看。**
