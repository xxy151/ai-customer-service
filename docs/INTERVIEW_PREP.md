## 🔧 核心代码展示

### 1. AI对话引擎

```python
def get_ai_response(user_input, user_type):
    """根据用户输入获取AI回复"""
    # 1. 检查知识库(快速响应)
    kb = knowledge_base.get(user_type, {})
    for key, value in kb.items():
        if key in user_input:
            return value
    
    # 2. 调用AI模型(复杂问题)
    system_message = system_messages.get(user_type, "")
    response = client.chat.completions.create(
        model="gpt-4",
        messages=[
            {"role": "system", "content": system_message},
            {"role": "user", "content": user_input}
        ]
    )
    
    return response.choices[0].message.content
```

**设计思路**:
- 先查知识库,命中则直接返回(毫秒级响应)
- 未命中则调用AI模型(秒级响应)
- 平衡响应速度和智能程度

## 🎯 项目难点与解决方案

### 难点1: 用户类型识别

**问题**: 如何让系统理解不同用户的需求差异

**解决方案**:
- 在登录时选择用户类型
- 为每种用户类型配置专属知识库
- 调整AI模型的system prompt
- 侧边栏提供用户类型切换功能

**代码实现**:
```python
system_messages = {
    "电商用户": "你是一个专业的电商客服人员,用友好专业的语气回答...",
    "企业用户": "你是一个专业的企业服务顾问,用专业严谨的语气回答..."
}
```

### 难点2: 响应速度优化

**问题**: AI模型调用延迟高,影响用户体验

**解决方案**:
- 知识库缓存: 常见问题直接返回
- Streamlit缓存: `@st.cache_data`
- 异步处理: `asyncio`
- 预加载: 应用启动时加载知识库

**性能数据**:
- 知识库匹配: <100ms
- AI模型调用: 2-5秒
- 页面加载: <1秒

### 难点3: 微信小程序集成

**问题**: 小程序与后端API的通信和认证

**解决方案**:
- 使用HTTPS保证安全
- JWT Token认证
- CORS跨域配置
- 小程序云开发(可选)
